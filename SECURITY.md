# Security and privacy

This independent downstream is a development preview. No supported public
release or guaranteed response time is declared.

**Do not post exploitable vulnerabilities or private mail/account data in a
public issue.** Once this repository is public, use GitHub's private vulnerability
reporting only if its Security tab explicitly offers it. That channel is not
assumed to be enabled. Otherwise contact the repository owner through an already
established private channel and first ask for a safe reporting route; no new
public contact address is invented here.

Share only the minimum synthetic reproduction, affected commit and environment.
Redact account addresses, message bodies, subjects, tokens, contact photos and
filesystem paths. Never attach a profile, mail store, signing key or credentials.

Do not run destructive experiments against live mail. Notification Delete is
intended to move one message to existing Trash, not permanently delete it;
visible desktop acceptance still needs verification. Known non-security defects
and pending release checks are tracked in [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md).

For upstream vulnerabilities, coordinate privately with the affected upstream
maintainer once applicability is established; avoid implying that they maintain
or support this downstream.

Security contact: Markus Kainer (D3rPaPaH0d3n), projekt@kainer.co.at.
Please describe a synthetic reproduction; do not email account passwords or
private mail databases. No guaranteed response time is offered.
