# Original feature illustration

`inbox-details.svg` is editable original Briefwerk artwork, created 2026-10-26
with OpenClaw assistance from new shapes and text. `inbox-details.png` is its
1440×900 system-rendered preview. **It is not an application screenshot.**

Alex Kim, Sam Rivera, all example.org addresses, subjects, times and the two-item
tray are synthetic. No accounts, messages, contacts, live desktop captures,
upstream screenshots, third-party logos or avatar providers were used.
