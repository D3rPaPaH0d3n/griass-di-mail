**Subject:** Name guidance / written permission enquiry — “Griabuntu Mail”

Hello Canonical legal / trademark team,

We are privately preparing an independent, open-source Linux desktop email
application under the proposed name **Griabuntu Mail**. It is a modified Convey /
Geary-derived mail client, not an Ubuntu distribution, flavour or Canonical
product. Its intended interface uses native GTK4/libadwaita controls and aims to
work comfortably on Ubuntu/GNOME and other supported Linux desktops.

We have read section 4 of your intellectual-property policy, including the
provisions concerning sufficiently similar UBUNTU/BUNTU-ending marks, software
titles and written permission. Because the proposed name includes “buntu”, we
would appreciate your assessment of whether this use requires permission and,
if so, whether written permission could be granted and on what conditions.

The proposal uses an original folded-G/mail symbol, pastel teal and copper
colours; no Ubuntu/Canonical logo, official-status claim, borrowed brand artwork
or endorsement is proposed. An independence disclaimer would be included, but
we understand that a disclaimer alone does not settle trademark permission.
We are seeking guidance before taking this private candidate name public.
We can supply the candidate artwork and intended uses for review if requested
and authorised.

Please advise whether the name is acceptable for an independent mail
application, which uses would be covered by any permission, and whether you need
further information before making a decision. We will not represent this enquiry
or any silence as approval.
