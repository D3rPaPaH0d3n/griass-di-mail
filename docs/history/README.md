# Historical upstream and handoff material

These files preserve their original names, content, authorship and context as
provenance. They are not current Griabuntu Mail launch/build/publishing inputs.
The original Flatpak templates are likewise under `packaging/historical/`.
The old metainfo includes upstream release notes/screenshots; those screenshots
are not presented as images of Griabuntu Mail. No historical publisher identity
or signing configuration is adopted by this project.

The current identity and intentional legacy keys are documented in
[../IDENTITY.md](../IDENTITY.md). Copyright/licence texts, source conversion
inventories and the dated `docs/release/` records remain unchanged evidence of
the particular older source/artifact they identify.
