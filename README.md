Convey: Send and receive email
=============================

Convey is an email application built around conversations, for the
GNOME desktop. It allows you to read, find and send email with a
straight-forward, modern interface.

Convey is a hard fork of [Geary](https://gitlab.gnome.org/GNOME/geary),
and is not affiliated with or endorsed by the GNOME Foundation.

Installation
--------------------

You can install Convey through my Flatpak repo:

```bash
flatpak remote-add --if-not-exists donnybeelo https://releases.donnybeelo.net/donnybeelo.flatpakrepo
flatpak install donnybeelo net.donnybeelo.Convey
```
